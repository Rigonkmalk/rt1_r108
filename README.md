# RT1 R108 - Administration Systèmes et Scripting Bash

Ce dépôt contient les travaux pratiques du module R108 de l'IUT de Béziers pour la formation RT1 (Réseaux et Télécommunications).

## Contenu

### TP1 - Système de fichiers
Introduction aux commandes Linux de base : navigation dans l'arborescence, éditeurs de texte, gestion des répertoires et fichiers.

### TP3 - Programmation Shell
Bases de l'écriture de scripts Bash :
- Boucles `while` et `for`
- Structures conditionnelles
- Gestion des paramètres et arguments
- Modification des droits de fichiers

### TP4 - Programmation Shell (suite)
Approfondissement des scripts Bash :
- Variables d'environnement
- Statuts d'exécution des commandes
- Interactions utilisateur avec `read`

### TP Eval - Évaluation
Évaluation pratique couvrant :
- Création et navigation dans l'arborescence
- Manipulation de fichiers et permissions
- Recherche avec `grep` et expressions régulières
- Création de scripts Bash
